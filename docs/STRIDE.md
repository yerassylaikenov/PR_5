# STRIDE — модель угроз (PR5)

Компоненты системы: **dApp** (браузерный клиент), **кошелёк** (MetaMask, EIP-1193),
**RPC** (локальный узел Hardhat, 8545), **смарт-контракт** `PaymentOrderRegistry`.

Границы доверия и точки проверки полномочий (см. схему `docs/architecture/PR5_Architecture.png`):
- **AC-1 (UI):** проверка роли в интерфейсе — только UX, не авторитетна.
- **AC-2 (кошелёк):** подпись транзакции доказывает владение ключом, но не полномочия.
- **AC-3 (контракт):** `onlyRole` по `msg.sender` — **единственная авторитетная** проверка.

Оценка риска: вероятность × влияние по шкале Низк./Сред./Выс.

## Неприменимые категории OWASP SC Top 10 (2025)

- **SC02 Price Oracle Manipulation** — не применимо: оракулов и цен нет.
- **SC05 Reentrancy** — не применимо: контракт не делает внешних вызовов/переводов ETH, нет `receive/fallback`; схема CEI.
- **SC06 Unchecked External Calls** — не применимо: внешних вызовов нет.
- **SC07 Flash Loan Attacks** — не применимо: балансов и ликвидности нет.
- **SC09 Insecure Randomness** — не применимо on-chain: соль для `paymentId` генерируется off-chain CSPRNG.
- **SC08 Integer Overflow/Underflow** — закрыто: Solidity 0.8.x (checked math) + `SafeCast` для `uint64`/`uint128` (проверяется property P1 на границах `1` и `type(uint128).max`).
